Ch 01 — Foundations

What Makes an AI Agent?

An LLM alone is just a text predictor. Wrap it with four capabilities and you get an autonomous agent that can plan, act, remember, and adapt.

Agent Anatomy — The Four Pillars
Key InsightA chatbot responds. An agent acts. The difference is autonomy: an agent chooses its next step based on observations, not a scripted response tree.
Ch 03 — Reasoning Patterns

The ReAct Loop

ReAct (Reasoning + Acting) is the heartbeat pattern of every LangChain agent. The model alternates between thinking and taking action until it has a final answer.

ReAct: Think → Act → Observe
Chain-of-Thought (CoT)
Forces the model to reason step-by-step before answering. Add "Think step by step" to your prompt. Reduces hallucination on math & logic tasks by up to 40%.
Tree-of-Thought (ToT)
Branches the reasoning into multiple paths simultaneously. Each branch is evaluated and pruned. Best for complex planning problems where the first idea is rarely the best.
Tool Calling
LLM outputs structured JSON describing a tool name + arguments. Your code executes the tool. Result injected back as an Observation. Requires models trained on function calling.
Formula ReAct = Reasoning (CoT) + Acting (Tool Calls) + Grounding (Observations). The loop terminates when the model outputs a Final Answer instead of an Action.
Ch 05 — Retrieval-Augmented Generation

The RAG Pipeline

RAG gives LLMs access to your own data without fine-tuning. Two phases: offline indexing and online retrieval. The key insight: search by meaning, not keywords.

RAG: Index Phase + Query Phase
Why it worksVectors encode semantic meaning, not literal text. "Car" and "automobile" are close in vector space. LLMs hallucinate less when given retrieved context because they're completing, not generating from scratch.
Ch 06 — Agents & Memory

The Four Memory Types

Agents need different kinds of memory for different jobs. Choosing the wrong memory type is the #1 cause of agents "forgetting" or being slow.

Episodic Memory
Conversation history — "what happened in this session". Stored in ChatMessageHistory. Short-lived. RAM or Redis. Analogy: your short-term recall of this conversation.
Semantic Memory
Facts & knowledge — "what I know about the world". Stored in a Vector DB (ChromaDB). Long-lived. Supports RAG. Analogy: your knowledge of Python syntax.
Procedural Memory
How to do things — skills, workflows, system prompts. Baked into the prompt or tools. Analogy: knowing how to type without thinking about each key. Rarely changes at runtime.
Working Memory
Current task context — everything in the active LLM context window. Includes messages, tool results, scratch-pad reasoning. Limited by token budget. The most critical to manage.
ConversationBufferMemory
Stores full history. Simple. Gets expensive fast. Use for short sessions only. After ~20 turns, swap to ConversationSummaryMemory to compress older turns.
VectorStoreMemory
Stores memories as embeddings. Retrieves the most relevant K memories per turn. Scales to thousands of past interactions. The production choice for long-running assistants.
Ch 07–08 — LangGraph

Stateful Workflows as Graphs

LangGraph replaces "the LLM decides everything" with explicit, debuggable state machines. Nodes are functions. Edges are conditions. State is a typed dict that flows through every node.

LangGraph State Machine with Human-in-the-Loop
State Reducers (Ch 08) Default: last-write-wins. Use operator.add as a reducer to append to a list (e.g. messages). Use max to keep the highest confidence score. Reducers = concurrency-safe state merging.
Common Mistake Naming a LangGraph node the same as a state key causes a silent collision. Your state update never applies. Always namespace nodes distinctly from state keys.

Supervisor / Worker Pattern

A single agent is a generalist. A team of specialists, coordinated by a Supervisor, solves enterprise-scale problems. Each worker owns one domain. The Supervisor routes, not executes.

Ch 10–12, 14 — Production

The Production Stack

Moving from notebook to production requires four layers beyond the agent itself: an API layer, observability, cost tracking, and safety guardrails.

Production Architecture Layers
FastAPI Essentials (Ch 11)
Use StreamingResponse for SSE. /health endpoint returns model status + DB ping. Load secrets from env vars, never hardcode. Use lifespan context for startup/shutdown.
Langfuse: AI-Specific Telemetry (Ch 12)
Traces every LLM call: model, tokens, cost, latency. Tracks cost-per-user. Manages prompt versions — deploy new prompts without code deploys. Collects user feedback scores for RLHF loops.
